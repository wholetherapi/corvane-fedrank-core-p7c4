# Corvane FedRank Core

Reference implementation of the FedRank Replicator (DIST 2025).

## Status

Released - v2.1.0. This is the maintained implementation. The older
`corvane-fdr-scratch-p7c4` prototype is archived and is not the reference
artifact; use this repository instead.

## Layout

- `src/` - replication and ranking code
- `data/` - shard manifests
- `experiments/` - reproduction scripts
